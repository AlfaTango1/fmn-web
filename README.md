# Flight Mission Navigator для iPhone / iPad

На iPhone программа ставится как веб-приложение: значок на главном экране, открывается на весь экран, работает GPS и без интернета (после первого запуска).

## Шаг 1. Новый репозиторий (отдельный от APK)

1. github.com → **+** → **New repository**.
2. Имя: `fmn-web`.
3. **Public** — бесплатный GitHub Pages работает только с открытыми репозиториями. Ключа подписи и ваших заданий здесь нет — только программа.
4. **Create repository**.

## Шаг 2. Загрузить файлы

1. **uploading an existing file**.
2. Выберите все 6 файлов из архива: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
3. **Commit changes**.

## Шаг 3. Включить сайт

1. **Settings** (в телефоне: **More → Settings**) → слева **Pages**.
2. **Source:** **Deploy from a branch**.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты вверху страницы появится адрес: `https://ВАШ-ЛОГИН.github.io/fmn-web/`.

## Шаг 4. Установить на iPhone

1. Откройте адрес в **Safari** (именно Safari).
2. Кнопка **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Запускайте программу **значком FMN** на главном экране.
4. Разрешите доступ к геопозиции. Если не спросило: **Настройки → Конфиденциальность → Службы геолокации → Сайты Safari → При использовании**, включите **Точная геопозиция**.

## Важно для iPhone

- Первый запуск — с интернетом, затем программа работает и без него. Карты района заранее загрузите: **Настройки → Карты без интернета**.
- Экран не гаснет, пока программа открыта (iOS 16.4 и новее).
- iPhone может удалить данные веб-приложения, если долго не пользоваться. Периодически сохраняйте пакет: **Настройки → Перенос на другое устройство → Сохранить пакет** (файл попадёт в «Файлы»).
- Обновление: загрузите новый `index.html` в репозиторий → через 2 минуты откройте программу с интернетом, закройте и откройте снова.
